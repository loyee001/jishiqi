# 此刻 · 100 小时计时器

支持 0–100 小时倒计时和正计时。可暂停、继续、重置，带到时声音与视觉提醒，适配手机和电脑。

直接双击 `此刻计时器.html` 即可离线运行，无需安装依赖；它是一个自包含文件。开发源码位于 `dist/`，也可以直接打开 `dist/index.html`。也可以在本目录执行 `python3 -m http.server 4186 --directory dist`，然后访问 http://localhost:4186。

倒计时可以设置 0–100 小时（分钟、秒均为 0–59，总时长不超过 100 小时）；0 秒不能启动，至少设置 1 秒。正计时从 0 开始，达到 100 小时自动停止。

使用时间戳计算，切换标签页后会校准时间。设备休眠或浏览器限制后台活动时，到时声音可能延迟；刷新或关闭页面会清除本次计时。空格键开始/暂停，表单输入和按钮获得焦点时保留原生键盘操作。

数字使用带闪电切口的立体科技风样式。倒计时开始后，剩余 10 秒及以下变为红色；暂停与完成保持提醒色，重置恢复冰蓝色。正计时保持冰蓝色。

计时背景音乐：David Lowe 的 **BBC World News 2013 Countdown**，通过[作曲家官网](https://davidlowemusic.com/project/bbc-news/)的公开在线试听音源播放，曲长约 64 秒；默认开启、音量 35%。不超过曲长的倒计时播放音乐的末尾片段，例如 10 秒倒计时从第 54 秒开始，30 秒从第 34 秒开始，结尾不再循环。暂停后继续、关闭后重新开启音乐时，按实际剩余时间重新对齐结尾；加载和缓冲恢复后也会校准位置。较长倒计时及正计时仍循环播放。重置和结束时停止并归零。背景音乐与到时提醒分别控制，音量滑杆仅控制背景音乐。网络或浏览器限制播放时会显示提示，可关闭音乐后重新开启。

计时和到时提示可离线使用；BBC 背景音乐需要联网，未复制音频到此仓库，也未嵌入单文件版。作品权利归相关权利人所有，在线试听不表示取得再分发许可。官方音源：<https://davidlowemusic.com/wp-content/uploads/2018/07/BBC-World-News-2013-Countdown.mp3>。
